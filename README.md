# README

## Описание проекта

Приложение представляет собой утилиту для выгрузки данных, преобразования их формата и последующей загрузки в базу данных PostgreSQL, а также сохранения результатов в виде JSON и XML файлов в архив.

## Структура проекта

Проект разделён на несколько ключевых компонентов:

- **App.java** — точка входа в приложение, содержит метод `main`, инициализирует основные модули и запускает выполнение программы.
- **Service.java** — реализует основную бизнес-логику выгрузки данных и передачи их другим компонентам для дальнейшей обработки.
- **Repository.java** — отвечает за взаимодействие с базой данных PostgreSQL, включая загрузку данных.
- **Archiver.java** — занимается упаковкой полученных данных в архив (формат ZIP), хранением как JSON, так и XML файлов.
- **XMLConverter.java** — конвертирует полученные JSON-данные в XML формат для последующего хранения.
- **DataResponse.java и DataItem.java** — вспомогательные классы, используемые для сериализации и десериализации JSON данных.

## Требования

Перед запуском убедитесь, что установлены следующие инструменты:

- JDK 8+
- Docker и Docker Compose
- Maven для сборки проекта

## Сборка проекта

Собрать проект можно командой:

```
mvn clean package
```

Эта команда очистит временные артефакты и соберёт исполняемый jar-файл.

## Развёртывание базы данных

Запустить контейнер с базой данных PostgreSQL можно командой:

```
sudo docker-compose up -d db
```

Данная команда запустит контейнер базы данных в фоновом режиме.

## Запуск приложения

Для запуска приложения выполните следующую команду:

```
sudo docker-compose run --rm app java -jar /app/app.jar <lastUpdateFrom> <lastUpdateTo>
```

Где `<lastUpdateFrom>` и `<lastUpdateTo>` — это начальная и конечная даты периода выгрузки данных соответственно, вводимые в формате `"dd.MM.yyyy"`.

Например:

```
sudo docker-compose run --rm app java -jar /app/app.jar 11.11.2025 12.11.2025
```
